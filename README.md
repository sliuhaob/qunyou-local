# 群友 · 本地分享版 0.1.0

在一台 Windows 电脑上，用你自己的 GPT 账号给你自己的微信群接话。机器人可以按语境不回复，支持短句、上下文、链接卡片文字和表情单帧理解；表情收藏与回复可选。

**使用自己的 ChatGPT / Codex 登录，无须填写 API Key；不需要远控或另一台电脑。** 若本机 CLI 原本通过 API Key 登录，则仍按其实际登录方式计费。

[下载 v0.1.0 试用版](https://github.com/sliuhaob/qunyou-local/releases/tag/v0.1.0) · [更新记录](CHANGELOG.md) · [参考与实现取舍](REFERENCES.md)

**前台操作限制：**准备监听、发送消息和截取表情时会短暂激活微信，之后尝试最小化；不能保证完全不抢焦点，Windows 桌面需要保持解锁。

这是从现有群友程序拆出的独立试用版。需要本机 Windows 10/11、64 位 Python 3.11–3.13（推荐 3.12，安装时保留 Tcl/Tk）、已登录的微信 4.x，以及能使用 Codex 的个人账号。微信只适配能暴露 `mmui::MainWindow` 等 UIA 控件的版本；不保证所有 4.x 小版本兼容。模型联网需要能正常访问 OpenAI。

## 给朋友的安装步骤

1. 解压 `QunYou-Local-0.1.0.zip` 到一个可写文件夹。不要在压缩包里直接运行。
2. 如果没有 Python，先从 [Python 官网](https://www.python.org/downloads/windows/)安装 3.12 64 位，保留 Tkinter。没有 Codex CLI 时还需要 [Node.js LTS](https://nodejs.org/)。
3. 双击 `01-install.cmd`。它在当前文件夹创建 `.venv`，安装指定版本的 Python 依赖；找不到 Codex 时通过 npm 安装官方 CLI 到 `tools/codex`。需要联网，无须管理员权限。
4. 双击 `02-open.cmd`，点击“登录自己的 GPT”，在官方页面登录你自己的账号。已经用官方 CLI 登录过时可复用本机登录。网页登录 ChatGPT 本身不代表 CLI 已登录。
5. 在微信中手动打开目标群。填写完整群名、本人群昵称、**全体成员显示昵称（每行一人，包含自己）**。昵称以聊天多选界面的显示为准，同名或含歧义前缀时先调整昵称。群名应唯一，暂不支持同名群及多群同时运行。
6. 填写机器人名字与人设，确认消息处理说明，保存配置。模型留空使用已安装 CLI 的默认模型；也可以填写你的账号实际支持的模型 ID。默认标准档，不强制 Fast。
7. 进入“检测与日志”，执行“环境与微信检测”和“测试 GPT”。前者不输入、不发消息；后者只生成一条本地测试回复，会消耗自己的模型额度。
8. 点击“启动群友”。它从启动基线之后的新消息开始处理，首次看到的历史只用于上下文。让其他群成员发一条新文字，核验一轮收发。

停止请点“停止群友”或双击 `03-stop.cmd`。**关闭配置窗口不会停止后台群友。** 重新打开窗口可查看状态。没有开机自启或系统服务。

## 使用时会发生什么

- 微信接收使用本机 UIA 多选模式，以完整名单匹配显示昵称并过滤本人消息。初次准备、发送、表情截图时会短暂把微信置前，完成后最小化。你操作键鼠、切到其他聊天或留下未发送草稿时，程序等待。
- 这版没有远控、SSH、隧道、桥接服务器、监听端口，也不需要作者的电脑在线；GPT 请求直接由你的官方 CLI 发起。
- 默认不开启表情收藏和表情回复。收到表情时仍会尝试截取这条表情的一帧供 GPT 理解；没有可用截图时按无图处理。开启表情开关后，程序可以收藏本群表情并从已有候选中选择回复。
- 昵称、指定群的消息和最近上下文，以及收到的表情单帧，会发给你登录的 GPT。链接只读微信卡片文字，不打开链接；不处理语音转写、完整视频或任意附件。
- 消息队列、截图、表情索引和日志保存在本地 `.runtime`。本程序不导入数据库密钥，不读微信本地数据库，不修改微信进程内存。没有遥测上传服务。
- 使用 ChatGPT 登录时按账号可用的 Codex 额度处理；若你的 CLI 用 API Key 登录则按 API 计费。登录与凭据由官方 CLI 管理，本程序不复制或展示凭据。查看登录方式：`codex login status`。
- 发送前再次核对群名、原消息和输入草稿。发送后检查本机回显；结果不明会暂停，不自动重发。回显不等于对方已读。

## 常见问题

| 状态 | 处理方式 |
| --- | --- |
| 未找到唯一微信窗口 / 控件缺失 | 登录微信，保留一个主窗口，打开目标群；保持微信和本程序权限一致。仍失败则该版本的 UIA 不兼容，暂不要启动。 |
| 群成员数量不同 / 发送者未知 | 停止程序，检查每个成员的显示昵称和人数；有人进退群或改名后重新保存。 |
| 等待切回目标群 | 手动打开配置中的目标群；程序不会替你切换到其他群。 |
| 无法置前 / 等待键鼠空闲 | 保持 Windows 桌面解锁，暂停键鼠操作；可先手动将微信放到前台。 |
| Codex CLI 版本过旧 | 通过官方安装方式更新 CLI；本地 npm 安装可执行 `npm.cmd install --prefix tools/codex @openai/codex`。 |
| GPT 生成失败 / 模型不支持 | 检查 CLI 登录与网络；清空模型名使用默认模型，或填写账号可用型号；保存前先停止。 |
| 发送结果未知 | 先核对微信实际是否发出。程序保留队列并停止后续发送，不提供一键重发，以免重复。需要人工核对队列后再恢复。 |
| 漏掉新消息 | UIA 只能看到客户端当前可访问的消息；滚动或快速刷屏可能使原消息离开列表，此时会丢弃旧回复。 |

聊天自动化会受到微信客户端版本及账号规则影响。先在知情的小群里验证，再长期使用。当前交付的离线检查与模型草稿测试不能替代接收者电脑上的真实收发验收。

## 配置和分发

使用配置窗口编辑 `config.json`。保存时派生 `bot_settings.json`、`sender_settings.json`、`persona.json`。请不要单独修改派生文件。更换目标群、本人昵称或名单后，旧队列和群资料归档到 `local_data`，不会对新群补发旧回复。

**转发给别人请发送干净的发布 ZIP，不要压缩整个用过的安装目录。** 在已配置的目录中执行 `python build_release.py`，只会按固定文件清单打包源码、说明和启动器；不会包含 `.runtime`、`local_data`、配置、名单、登录信息或已安装依赖。ZIP 内附文件 SHA-256 清单。

开发验证：`python -m unittest -v test_local`。测试不登录微信、不调用真实模型、不发送消息。

本仓库包含 18 项分享版测试；下面记录的另外 123 项回归测试来自原项目，未包含在这个独立仓库中。
